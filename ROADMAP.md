# Quantaflex Public Roadmap

This roadmap describes public product direction only.

Internal implementation details, proprietary codec research, algorithms, and confidential development milestones are intentionally excluded.

## Current Platform Direction

Quantaflex is being developed as one modular professional desktop platform.

Core principles:

- exact-lossless where applicable
- local-first processing
- professional desktop workflow
- modular capability structure
- efficient media preparation and delivery

## Product Modules

### Kineplex

Home Theatre and advanced playback environment.

### FlexCam

Social Video Edit & Posting Suite.

Planned areas include:

- import and proxy workflows
- timeline editing
- social format preparation
- titles and text
- music and audio
- captions
- export and posting
- brand assets
- platform previews

### Cam2Cam

Camera-to-camera communication and media workflow tools.

### Pro Online Learning

Professional tools for educators, training providers, and online learning workflows.

### Advanced Encoder

Advanced media preparation and encoding tools.

### RCA Toolkit

Research and analysis tools based on Quantaflex relational computation work.

## Release Direction

### Phase 1

- desktop platform foundation
- initial production modules
- macOS support
- Windows support
- licensing and distribution
- public community infrastructure

### Phase 2

- expanded FlexCam features
- wider format support
- workflow automation
- improved hardware acceleration
- community-requested features

### Phase 3

- advanced professional modules
- deeper encoder integration
- experimental tools
- new Quantaflex research capabilities

## Community-Funded Development

From 15 October 2026, Quantaflex sponsorship will help accelerate selected roadmap areas.

Community voting may influence development priority, but roadmap votes are advisory and do not create guaranteed delivery dates.

## Feature Sponsorship

Future sponsorship campaigns may support specific milestones such as:

- new platform modules
- hardware acceleration
- compatibility work
- advanced encoding
- accessibility improvements
- documentation
- testing infrastructure

Completed community-funded features remain part of the wider Quantaflex platform according to the applicable product licence.

## Roadmap Principle

We will publish what we are building without publishing how proprietary Quantaflex technologies are implemented.
