# Contributing to Quantaflex Community

Thank you for helping improve Quantaflex.

This is a community repository, not the Quantaflex production source repository.

## You Can Contribute By

- reporting workflow issues
- suggesting features
- discussing product ideas
- testing public builds
- reporting compatibility issues
- improving public documentation
- sharing professional use cases
- participating in roadmap discussions

## Please Do Not Submit

- reverse-engineered Quantaflex source
- decompiled binaries
- attempts to reproduce proprietary codec implementation
- confidential material
- leaked internal development information
- copied proprietary code
- security-sensitive information in public discussions

## Feature Requests

Good feature requests should explain:

1. the workflow problem
2. who encounters it
3. what outcome would help
4. which Quantaflex module it relates to

Implementation decisions remain with the Quantaflex development team.

## Bug Reports

Please include:

- operating system
- Quantaflex version
- hardware where relevant
- steps to reproduce
- expected behaviour
- actual behaviour

Do not post licence keys, private files, credentials, or personal information.

## Community Conduct

Keep discussion:

- constructive
- technical where appropriate
- respectful
- focused on improving Quantaflex

## Intellectual Property

Public discussion does not imply disclosure of proprietary implementation.

Quantaflex may discuss capabilities, performance, roadmap direction, and product behaviour without disclosing confidential algorithms or source code.
